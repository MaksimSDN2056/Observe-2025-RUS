# Русификатор для Observe (2025) [Build 24511706] (v1.0)

Фанатский русификатор для ранней сборки **Observe (2025)** от Kisotik Games (для версий до обновления 0.8.0, где ещё отсутствовал русский язык).

### Что переведено:
* Главное меню, настройки и элементы интерфейса
* Редактор сценариев и идеологий
* Панель управления (режим Бога)
* 171 современная страна, исторические государства и столицы
* Военная статистика и боевые сводки

### Скачать:
Перейдите в раздел **[Releases](../../releases)** справа и скачайте архив `Observe_2025_RUS_v1.0.zip`.

### Установка:
1. Распакуйте архив в любое удобное место в виде папки.
2. Запустите `Install_Rus.bat`, перетащите в окно корневую папку игры `game` (где лежит `Observe.exe`) и нажмите Enter.
3. Введите `yes` и нажмите Enter.

> **Примечание:** При первом запуске главное меню может отображаться на английском — просто откройте `PLAY` (или `OPTIONS`) и нажмите `BACK`, после чего весь интерфейс переведётся на русский язык.

### Удаление:
Запустите `Uninstall_Rus.bat` (из папки игры или из папки русификатора — при необходимости укажите путь к игре) и введите `yes`.
